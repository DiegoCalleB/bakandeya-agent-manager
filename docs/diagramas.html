2. Diagrama de flujo — la máquina de estados (lib/estados.py)

Cada flecha sólida es una transición del "camino feliz", con el agente que la ejecuta como etiqueta. Las flechas discontinuas son caminos secundarios (rechazos, vueltas atrás). Casi cualquier estado activo puede pasar a descartado a criterio humano — para no saturar el dibujo, solo se traza esa flecha desde no_interesado.
